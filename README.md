# Hermez - Aplicación

Aplicación web creada para gestionar el registro de domicilios y su estado de pago, dando solución a una problemática que surgió en mi trabajo durante temporada alta. La falta de un sistema para llevar el historial de pagos y su estado generaba inconformidades tanto en clientes como en domiciliarios. **Hermez** es mi solución a este problema, ofreciendo un registro fácil de usar, eficiente y con un diseño minimalista.

> 🔄 **Nota:** La aplicación está en desarrollo activo, implementando mejoras continuas tanto en funciones como en diseño UX/UI.

## Tecnologias utilizadas
- astro
- tailwind
- typescript
- firebase
- turso
 
## Uso
1. Iniciar sesión con credenciales válidas
2. Registrar nuevo domicilio
3. Actualizar estado de pago cuando corresponda
4. Consultar historial cuando sea necesario
